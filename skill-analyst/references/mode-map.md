# 模式×阶段映射与节点图规范（skill-analyst）

## 模式映射

| 模式 | 阶段 | 输出 | 适用 |
| --- | --- | --- | --- |
| Quick | 0→1→2→4 | 四维摘要 + P0-P3 问题清单 | 单文件快查、时间紧 |
| Full | 0→6 全走（含 3 动态实证） | analysis.json + 节点图 + 优化计划 + eval 建议 | 优化决策、发布前 |
| Batch | 先 0 全目录统计 → 四维快筛 → Top 异常 Full | 目录体检表 + Top 报告 | 「分析本地技能库」 |
| Profile | 0→1→2 | 身份卡（核心目的/意图/逻辑/实现效果/重要场景/注意事项） | 「介绍一下这个 skill」「给我一张身份卡」 |

> JSON 约定：analysis.json 的 mode 字段一律小写（quick/full/batch）。

## 节点图规范（Mermaid）

- 节点 = 方框；决策门 = 菱形 `{...}`；人工确认门标注 `HUMAN_GATE`
- 循环 = 回到上游节点；跨切面约束（如上下文保护）用虚线 `-.->` 标注，不占步骤号
- 死节点/不可达出口用 `style X fill:#fdd` 标注
- 每张图必须能回答：入口、出口、每个分支去哪、人工门在哪
