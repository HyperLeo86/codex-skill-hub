# 追溯矩阵

## ID 规则

- 需求：`FR-001`（功能）/ `NFR-001`（非功能）
- AC：`AC-001` 或 `AC-3.1`（关联规则编号）
- 测试：`TC-001`

## 矩阵格式

| 需求 | AC | 测试用例 | 目标指标 |
| --- | --- | --- | --- |
| FR-001 | AC-001 | TC-001 | M1 |
| FR-002 | AC-002, AC-003 | TC-002, TC-003 | M2 |

## 检查

```bash
python3 scripts/traceability_check.py <PRD 路径> [acceptance-map.md]
```

- 孤儿需求：无 AC 的需求
- 孤儿 AC：无需求引用的 AC
- 孤儿测试：无 AC 引用的测试

## 规则

- 每条功能需求 ≥1 AC；每条 AC 必须引用 ≥1 需求；测试必须引用 AC。
- 变更时先改矩阵再改正文，保持双向一致。
- 脚本只做机械检查；语义一致性由 review-standard.md 横向维度 2 覆盖。
