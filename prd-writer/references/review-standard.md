# 纵横双轴审核标准

## 纵向（逐模块条款）

逐模块对照 outline.md 内容约束卡；缺项列「缺什么 + 证据（引位置）」。

- 模块 1：版本/变更记录是否真实存在
- 模块 2：证据是否有来源；无来源是否标 `[ASSUMPTION]`
- 模块 3：指标是否有口径与周期；是否有反指标
- 模块 4：非范围与假设是否显式；假设不成立的处置
- 模块 5：角色权限、主路径、高频异常是否覆盖
- 模块 6：每条规则是否有例子；状态/字段/错误是否闭环
- 模块 7：每条需求是否有 AC；AC 是否可测、无歧义、覆盖异常、可追溯
- 模块 8：埋点/灰度/回滚/风险是否齐全

## 横向（七维一致性）

1. 术语一致：同一概念同一叫法，无自造词
2. 需求追溯：每条需求 → 目标/范围/指标
3. 字段口径：同一字段定义一致
4. 状态闭环：每个状态有入口/出口/异常
5. 角色权限：权限与角色矩阵一致
6. 范围边界：Must 与 Not now 不打架
7. 可测性：所有规则/需求都有可判定标准

## 问题分级

- **阻塞**（会导致返工/歧义）：必须清零才交付
- **建议**（可改进）：记录，不阻塞
- **风格**（排版/措辞）：记录，不阻塞

## 报告格式

```markdown
# PRD 审核报告

## 纵向
- [阻塞] 模块6：规则 R3 缺例子（§6.2）

## 横向
- [阻塞] 术语：模块 5 用「客户」，模块 6 用「甲方」（§5.1/§6.3）

## 分级汇总
- 阻塞 X / 建议 Y / 风格 Z
```
