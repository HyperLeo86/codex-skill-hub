# PRD 反例片段与问题标注

## 原文（反例）

> 做一个人事审批功能，支持请假、加班、报销等流程。提交后尽量快点处理，管理员可以审批，审批时可以看到相关信息。权限要合理，性能要好，上线后要观察数据。系统要稳定、安全、可扩展。

## 问题标注

- 「支持请假、加班、报销等流程」：`等` 范围未定 → 需要 Must / Not now 清单
- 「尽量快点处理」：无 SLA 数值 → 需要可测指标
- 「管理员可以审批」：角色/权限矩阵缺失 → 需要角色与字段级权限
- 「相关信息」：字段口径缺失 → 需要字段清单
- 「权限要合理、性能要好、稳定安全可扩展」：NFR 剧场 → 需要阈值与测试口径
- 「上线后要观察数据」：无埋点口径与周期 → 需要数据源/指标定义
- 全文无 AC、无例子、无假设索引、无变更记录
