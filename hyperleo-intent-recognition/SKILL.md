# hyperleo-intent-recognition

**版本**：0.1.0（2026-08-08）

## 概览

任务/技能开工前的意图识别与澄清：识别真实意图、澄清模糊目标、输出意图卡（What/For whom/Decision/Success signal/Relationship），确认后放行

## 触发与反触发

- 触发：先帮我理清楚我要做什么；帮我识别一下我的真实意图；我有个想法但说不清目的；开工前先帮我澄清目标和意图；这个需求背后到底想解决什么；帮我确认一下我到底想干嘛；先别动手，帮我梳理一下目标；帮我做一件事之前，先确认我的意图
- 反触发：直接执行任务本身（意图识别只做前置门，不代工）；技能封装与 SKILL.md 生成（走 skill-forge）；深度用户调研/访谈执行（走 prd-writer 三视角访谈）

## 决定权（自由度 medium）

- 按伪代码/模板执行，参数可依上下文调整
- 输出格式遵循模板，内容允许合理变化

## 工作流

1. **识别**：从用户原话提取显性意图 + 上下文线索（对象/场景/约束/关系）。能直接推断的不问（规则优先）。
2. **澄清**：置信度低、字段缺失或存在互斥解释时，用非引导式提问（≤3 问；题库见 `references/question-bank.md`）。
3. **确认**：输出意图卡（模板见 `references/intent-card.md`），请用户确认或修正。
4. **放行/退回**：确认后放行；用户修正后重出意图卡，旧卡保留对照。
5. **输出**：意图卡 + 澄清记录 + 放行/退回结论，交给下游技能或任务。

## 验收（来自契约）

- 输出五字段意图卡，每字段 ≤20 词
- 澄清轮次 ≤3，且所有提问为非引导式
- 用户确认后放行；用户修正后重出意图卡
- 置信度高时不强行追问，直接出卡

## 失败降级

- 用户不配合澄清 → 输出带 [ASSUMPTION] 标签的意图卡并标「待确认」，不阻塞放行
- 存在多个互斥意图 → 输出候选意图列表让用户选择，不自行合并
- 完全无上下文（只有孤词） → 先问「对象/场景/目的」三件事，不猜
- 用户中途换意图 → 重跑识别层，旧意图卡保留作对照
- 下游无消费方（意图卡没人用） → 仍输出意图卡并标注「待接入」，不拒绝服务
