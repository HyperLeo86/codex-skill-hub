# 海报验收清单与证据规则

## 自检六项（缺一不可）

1. 交付物是 PNG 海报 + HTML 源
2. 不是结构图/流程图（无 Mermaid、SVG、架构图）
3. 海报含：标题 / 一句话定位 / 比喻三要素 / 3–5 个要点 / 模块标签 / 证据脚注
4. 比喻「像什么 / 哪像 / 哪不像」齐备
5. 模块可替换判定三档（可替换/难替换/不可替换）+ 理由
6. 渲染可复现：本地 Chrome 从 HTML 源截图成功

## 证据规则

- 静态事实以 analyze_skill.py 输出为准，禁止即兴重算
- 无证据的判断必须标「待验证」，禁止编造
- 长文档走渐进式披露：先 frontmatter/标题/工作流，再按需 references
- 目标脚本无法运行 → 静态分析 + 标「未实证」

## 模块可替换判定

| 档位 | 判据 | 例子 |
| --- | --- | --- |
| 可替换 | 存在等价现成组件，替换不影响核心契约 | 渲染层、示例数据 |
| 难替换 | 绑定特定脚本/模型/目录约定，换掉要同步改多处 | 自定义脚本、schema |
| 不可替换 | 是技能存在理由本身（触发面/核心步骤/验收） | 核心工作流 |

## 仅名称查找顺序

1. 本地：`rg --files ~/.codex/skills ~/.agents/skills ~/.claude/skills 2>/dev/null | rg '/SKILL\.md$'`，按 description 关键词匹配，列出候选让用户确认
2. 深挖（可选）：hyperleo-world-search-pro 多引擎查找
3. 都没有 → 明确输出「未找到」+ 相近本地项，停止

## 降级规则

- 返工超过 2 轮仍不达标 → 输出 Markdown 版卡片 + 头部标注「未完全达标」
- Chrome 渲染失败 → 交付 HTML 源 + 标注「未渲染」
- AI 插画失败 → 纯 CSS 海报，不阻塞
- 目标不是 skill（普通仓库）→ 输出仓库概览并说明，不硬套海报
