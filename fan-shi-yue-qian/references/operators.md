# 十类跃迁操作子（判别问题表）

给每个优秀方案打上操作子标签，形成「机制签名」；签名相同 = 可跨域类比。

| 操作子 | 一句话机制 | 如何识别（判别问题） | 经典例子 |
| --- | --- | --- | --- |
| 删除 | 证明某些工作根本不必做 | 哪一步的输出从来没人用？ | Karatsuba 减少子乘法 |
| 转换 | 难问题转成易问题 | 能不能换个可测量的量？ | 质量→频率、位置→相位 |
| 分解 | 整体拆成局部 | 能不能分而治之？ | 有限元、动态规划 |
| 聚合 | 逐个处理→成组处理 | 哪些对象可以归组？ | 批量、分桶、缓存 |
| 并行 | 顺序→同时 | 哪些步骤彼此独立？ | 并行计算、批量制造 |
| 反馈 | 一步到位→测量校正 | 能不能先做再测再调？ | 牛顿迭代、卡尔曼滤波 |
| 稀疏采样 | 全采→只采足够恢复的量 | 数据里是否有冗余结构？ | 压缩感知、主动学习 |
| 容错重建 | 每步正确→整体恢复 | 能不能容忍局部失败？ | 纠错码、鸟枪测序 |
| 标准化接口 | 内部差异→统一接口 | 能不能封装差异？ | 集装箱、编译器 IR |
| 可编程化 | 每个目标造工具→参数化 | 能不能用数据/指令驱动？ | CRISPR、软件定义无线电 |

## 五问（机制抽象强制步骤）

1. 它停止做了什么？
2. 它把什么问题转换成了另一个问题？
3. 它改变了哪个成本增长关系？
4. 它利用了什么过去被视为缺点的东西？
5. 它增加了哪个新的中间层、变量或反馈回路？
