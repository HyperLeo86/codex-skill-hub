# 失败模式 → 人文概念映射库

## 0 使用规则

- 主模式取最匹配的一层，可加副模式；每个标签必须回指时间线证据节点
- 无法归类时输出「未知模式 + 证据摘要」，禁止硬套标签

## 1 第一层：五域分类（AgentErrorTaxonomy 精简）

| 域 | 典型信号 | 检查点 |
| --- | --- | --- |
| 记忆域 | 关键上下文/前提丢失、跨会话假设失效 | 目标、约束、已做决策是否全程可追溯 |
| 反思域 | 自评错误、误判已完成、复盘结论自洽但错误 | 完成判据是否来自验证而非感觉 |
| 规划域 | 任务分解错误、目标漂移、步骤顺序错 | 计划与目标是否逐层一致 |
| 动作域 | 工具参数错、调用错、选了错误工具 | 每个动作的输入输出是否符合工具契约 |
| 系统域 | 环境缺失、限流、网络、基础设施 | 环境假设是否被实际验证 |

## 2 第二层：操作四分类（failure-reflection）

| 类型 | 信号 | 正确行动 |
| --- | --- | --- |
| 参数错误 | 400、类型不匹配、missing required field | 对照工具描述修正参数后重试 1 次 |
| 前提不满足 | ENOENT、资源未初始化、依赖未创建 | 先满足前提再重试 |
| 环境缺失 | 命令不存在、权限不足、网络断开 | 用只读命令确认环境，不猜 |
| 策略错误 | 步骤正确但无推进、同类失败 ≥2 次 | 换工具/换路径/换策略并记录教训 |

## 3 第三层：常见行为模式（社区技能模式）

- 过早行动：未经批准或验证就动手 → 加批准门/预检
- 顺序错误：依赖链未满足就执行 → 编号步骤 + 依赖检查
- 缺失验证：改完不验、只信 exit code → 加验收检查点
- 上下文残留：假设上一会话状态仍存在 → 任务开始先验证状态
- 范围蔓延：做了超出请求的事 → 澄清边界，非目标显式记录
- 循环重试：同类失败 ≥2 次仍同路径 → 停止，换策略
- 静默失败：返回正常但结果错 → 校验真实结果而非状态码
- 目标劫持：外部内容静默替换任务目标（安全维度） → 意图-行为一致性核验

## 4 因果纪律

- 相关 ≠ 因果三要素：机制可陈述 + 判别证据 + 反事实检验
- 症状消失 ≠ 根因已修（可能存在共同隐藏原因）
- 单因思维：先找直接原因，但不允许停在直接原因
- 空泛规则：「以后小心点」不是规则；必须可检查、可执行

## 5 人文概念映射表（输出人文性错误/概念时用）

| 失败模式 | 贴切的人文概念 | 一句话解释 |
| --- | --- | --- |
| 局部采样当全局结论 | 盲人摸象 | 只摸到局部就断言全局 |
| 只按新名字找配置、旧路径看不见 | 灯下黑 | 最该看见的旧配置就在眼皮底下却看不见 |
| 用旧假设处理已变化的环境 | 刻舟求剑 | 记号在船上，剑早已不在原处 |
| 用错误手段解决错误 | 抱薪救火 / 南辕北辙 | 方法方向反了，越用力越糟 |
| 死守旧经验不试新路 | 守株待兔 | 把偶然当规律 |
| 重复同样动作期待不同结果 | 缘木求鱼 | 方法本身与目标不匹配 |
| 只改表面不改认知框架 | 讳疾忌医 | 不看真正病根 |
| 计划脱离实际执行 | 纸上谈兵 | 模型与现实脱节 |
| 事后归因掩盖真因 | 事后诸葛亮 | 解释很圆满，但当时看不见 |
| 当局者视角受限 | 当局者迷 | 身在局中看不到自己的盲区 |

找不到贴切条目时，宁可不出人文概念，也不硬凑。
