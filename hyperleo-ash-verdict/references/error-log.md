# 错误日志（DDC Cycle Log）

## 默认路径

`/Users/leo/Documents/HyperLeo's workspace/错误复盘/错误复盘日志.md`
（用户指定其他路径时跟随；拒绝落盘时只在对话内输出文本）

## 条目模板（每次复盘追加，表格形式，无背景说明）

```markdown
## YYYY-MM-DD · <任务一句话>

| 类别 | 内容 |
| --- | --- |
| **事实** | <日期时间与当时事实> |
| **技术性错误/缺失** | 1. <概念>：<为什么错><br>2. <概念>：<为什么错> |
| **人文性错误/概念** | <概念> —— <一句话解释>（可无） |
```

## 回访规则

- 回访时检查：同类失败是否再次发生？
- 复发 → 状态改「已复发」，重跑五步流程，并给该概念计数 +1
- 未复发 → 状态改「已回访」，回访日期顺延一轮
- 同一缺失概念重复出现：不新建条目，在最新条目上计数 +1 并提前回访
- 回访日期标注在条目正文末尾（`回访：YYYY-MM-DD`），不新增模板字段

## 收敛信号（DDC 假设）

- 连续 20-30 次复盘后，新增概念条目应递减
- 若每轮仍新增 ≥1 条：概念清单覆盖不足，需主动补领域知识而非继续等失败

## 数据用途

- 错误日志积累 ≥50 条后可试跑 BKT/IRT 做掌握度量化（当前为手工清单阶段）
- 每季度汇总一次：Top 技术性错误、Top 人文概念、复发率
