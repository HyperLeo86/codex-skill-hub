# 知识故障集（Knowledge Fault Set）

## 使用规则

- 定位失败点上的「本该用到的概念/框架」，命中即输出；未命中创建新条目（标「新增」）
- 每个条目字段：概念名 | 在什么设计决策中该出现 | 缺失时的典型症状 | 诊断检查
- 领域持续扩充；扩充来源：新失败、用户补学内容、领域标准（如 IETF NMOP、MITRE）

## 网络域

| 概念 | 该出现的决策 | 缺失症状 | 诊断检查 |
| --- | --- | --- | --- |
| TCP/IP 分层与封装 | 排障、抓包分析 | 只看应用层报错，找不到链路层问题 | 逐层验证（应用→传输→网络→链路） |
| DNS 解析链路 | 域名访问类设计 | 误判「服务挂了」，实际是解析/缓存问题 | dig/nslookup 全链路 |
| NAT/代理/隧道 | 内外网互通设计 | 直连可行、远端不可达 | 画数据路径，标每个跳点的源/目的地址 |
| 端口与防火墙 | 服务暴露设计 | 端口监听正常但外部连不上 | 本地/远端分别探测 + 防火墙规则核对 |
| 负载均衡与会话保持 | 高可用/水平扩展 | 登录态随机丢失 | 检查 LB 会话亲和策略 |
| 零信任/网络分段 | 安全架构设计 | 默认「内网即安全」 | 按身份/设备/上下文逐段授权 |
| Overlay/Underlay 与网络范式 | 容器/云网络设计 | 在虚拟网络里套物理网络思维 | 明确逻辑网络与物理网络的映射 |

## 安全域

| 概念 | 该出现的决策 | 缺失症状 | 诊断检查 |
| --- | --- | --- | --- |
| 认证/授权/会话 | 用户系统设计 | 只做了登录没做权限校验 | 每个接口过一遍「谁能调用」 |
| 最小权限 | 密钥/令牌设计 | 一把钥匙开所有门 | 按操作/资源拆分权限 |
| 威胁建模 | 方案评审 | 只考虑「正常路径」 | STRIDE 或攻击面清单过一遍 |
| 注入与输入校验 | 数据处理设计 | 信任外部输入 | 对每个外部输入做合法性边界 |
| 密钥管理 | 凭据落地 | 密钥写进代码/配置文件 | 环境变量/密钥库/轮换机制核对 |
| 会话污染/提示注入 | Agent 系统设计 | 外部内容能改变任务目标 | 隔离系统指令与外部内容 |

## AI 域

| 概念 | 该出现的决策 | 缺失症状 | 诊断检查 |
| --- | --- | --- | --- |
| 上下文窗口与检索（RAG） | 长文本任务设计 | 塞全文导致关键信息丢失 | 检索→排序→引用链验证 |
| 幻觉与验证 | 结果交付设计 | 模型自信但输出错误 | 每个结论要求可核验证据 |
| 嵌入/向量检索 | 语义匹配设计 | 关键词匹配失效 | 换向量检索并评测召回 |
| Agent 循环与工具调用 | 自动化流程设计 | 卡在重复调用同一工具 | 检查循环退出条件 |
| 评测/回归 | 改动后验收 | 改完只信 exit code | 建立最小评测集 |
| 意图-行为一致性 | 复盘归因 | 只从输出反推原因 | 逐节点核对行为是否忠于意图 |

## 文件/数据域

| 概念 | 该出现的决策 | 缺失症状 | 诊断检查 |
| --- | --- | --- | --- |
| 路径解析与权限 | 文件读写设计 | 找不到文件/权限被拒 | 用绝对路径 + 实际权限核对 |
| 编码与字符集 | 多语言数据处理 | 乱码、截断 | 从源头到输出统一编码 |
| 原子写与并发 | 状态持久化 | 写一半崩溃、竞态 | 临时文件+rename 或锁 |
| 备份/快照 | 破坏性操作前 | 数据丢失无法恢复 | 操作前快照 + 恢复演练 |
| 序列化/格式契约 | 跨系统交互 | 字段解析失败 | 版本化 schema + 校验 |

## 工程范式域

| 概念 | 该出现的决策 | 缺失症状 | 诊断检查 |
| --- | --- | --- | --- |
| 防御性验证/预检 | 开工前 | 假设未验证就动手 | 最小真实调用验证假设 |
| Fail-fast | 错误处理设计 | 错误被吞掉、症状延迟 | 检查静默 catch |
| 可观测性 | 系统设计 | 出问题时无日志可查 | 日志/指标/trace 三件套 |
| 契约测试/验收标准 | 任务定义 | 做完了但不知道对不对 | 先写可检查的验收再执行 |
| 版本控制与回滚 | 变更设计 | 改坏了无法还原 | 提交点 + 回滚路径 |
| 双环学习 | 复盘 | 只改行为不改认知框架 | 追问「我的设计范式哪里错了」 |
| 证伪思维 | 下结论前 | 局部观察当全局结论 | 先找反例再做最小实验 |

## 认知/方法域

| 概念 | 该出现的决策 | 缺失症状 | 诊断检查 |
| --- | --- | --- | --- |
| 基线对比 | 评估效果 | 无法判断改好改坏 | 记录改动前基线 |
| 反事实检验 | 归因 | 把相关当因果 | 「如果没做 X 会怎样」 |
| 稀疏采样 | 重读长会话 | 成本随长度线性涨 | 只读关键节点 |
| 去重与收敛 | 知识积累 | 同类错误反复记录 | 同概念计数+1 |

## 新建条目模板

```text
| <概念名> | <该出现的决策> | <缺失症状> | <诊断检查> |
```

新建时附：来源失败样本、证据、缺失类型；同一概念出现第 2 次起只计数。
