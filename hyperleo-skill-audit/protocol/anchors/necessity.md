# Necessity & Value Anchor（必要性与价值）

问题：即使有独立 Job，它是否值得被固化成 Skill？

## Positive
灾难恢复类 Skill：低频，但每次使用价值极高、流程复杂、普通 Prompt 无法稳定完成，且沉淀了不可轻易替代的方法论。

## Negative
只包含「整理笔记」通用步骤的 Skill：无独特方法论、无工具链、无资产，通用模型一次 Prompt 即可完成。

## Borderline
高频但通用模型已能稳定完成 → replaceability = HIGH；低频但价值极高且流程复杂 → 仍可成立。

## 判定规则
- usage_frequency 只能来自真实使用记录；无数据 → UNKNOWN，禁止猜测「应该是高频」。
- unique_assets = YES：存在不可轻易替代的方法论、工具链、测试或知识资产。
- 禁止用总分表达价值；价值以独立证据字段表达。
