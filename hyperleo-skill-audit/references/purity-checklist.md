# 纯粹性检查清单

## 单一职责

- 一句话能否说清这个 skill 的 Job？（说不清 → ⚠️）
- SKILL.md 的章节是否都在服务同一个 Job？（出现与 Job 无关的章节 → ⚠️）

## 触发边界

- description 正触发 ≥6 且全部指向同一 Job？（跨领域触发 → ⚠️）
- 反触发是否覆盖相邻技能？（无反触发 → ⚠️）

## 夹带领域

- 工作流里是否出现「顺带做」的其他任务（如检索时顺带写报告）？（有 → ⚠️）
- 输出里是否混入不属于 Job 的承诺？（有 → ⚠️）

## 判定

- 全部 ✅ → 纯粹
- 1 个 ⚠️ → 可接受，建议记录
- ≥2 个 ⚠️ 或任一 ❌ → 判定「不纯粹」，进入拆分/重构建议
