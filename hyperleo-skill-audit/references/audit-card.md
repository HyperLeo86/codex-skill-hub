# 裁决卡模板

```markdown
# 裁决卡：<skill 名>

## 1. 独立意图（调用 hyperleo-intent-recognition）
- 意图卡五字段摘要

## 2. 纯粹性
- 单一职责：✅/⚠️/❌（证据：SKILL.md 行号）
- 触发边界：✅/⚠️/❌（证据：description 触发/反触发）
- 夹带领域：✅/⚠️/❌（证据：工作流步骤）

## 3. 解耦
- 独立运行：✅/⚠️/❌
- 下游依赖：✅/⚠️/❌
- 与封装流程耦合：✅/⚠️/❌

## 4. 生态位
- 对比 skill 1：<名> — 触发重叠：低/中/高 — 输出重叠：低/中/高
- 对比 skill 2：<名> — 触发重叠：低/中/高 — 输出重叠：低/中/高

## 结论
- 判定：独立 / 合并（与谁）/ 拆分（拆成什么）/ 重构（改什么）
- 触发条件：什么情况下该执行此结论
- 失效条件：什么情况下此结论不成立
```
