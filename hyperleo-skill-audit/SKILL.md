# hyperleo-skill-audit

**版本**：0.1.0（2026-08-08）

## 概览

审视一个 Skill 的合理性：纯粹性、功能解耦、独立意图与生态位，输出裁决卡与「独立/合并/拆分/重构」建议

## 触发与反触发

- 触发：审视一下这个 skill 合不合理；这个 skill 纯粹吗；这个技能职责是不是太多了；检查一下这个 skill 是否解耦；这个 skill 有没有独立的生态位；两个 skill 是不是重叠了，该不该合并；帮我判断这个技能该独立还是该拆；审一下这个 skill 有没有独立意图
- 反触发：对 skill 做四维健康体检与优化方案（走 skill-analyst）；创建/升级技能本体（走 skill-forge）；把技能发布到 GitHub（走 skill-publisher）

## 决定权（自由度 medium）

- 按伪代码/模板执行，参数可依上下文调整
- 输出格式遵循模板，内容允许合理变化

## 工作流

1. **取证**：读目标 SKILL.md + references + 同级技能目录（≥2 个）。
2. **独立意图**：调用 `hyperleo-intent-recognition` 对目标 skill 出意图卡，识别它的真实 Job。
3. **纯粹性检查**：按 `references/purity-checklist.md` 检查单一职责、触发边界、是否夹带其他领域。
4. **解耦检查**：检查能否独立运行、输出是否依赖下游、是否与封装流程耦合。
5. **生态位检查**：对比 ≥2 个同级 skill 的触发词与输出重叠。
6. **裁决**：四选一结论（独立/合并/拆分/重构）+ 证据位置。
7. **交付**：输出裁决卡（模板见 `references/audit-card.md`），只读不修改目标。

## 验收（来自契约）

- 裁决卡含 4 项检查（纯粹/解耦/独立意图/生态位），每项附证据位置
- 独立意图检查调用 hyperleo-intent-recognition 输出目标 skill 的意图卡
- 生态位检查至少对比 2 个同级 skill
- 结论四选一（独立/合并/拆分/重构），附触发条件与失效条件
- 只读，不修改目标 skill

## 失败降级

- 目标路径不存在 → 停止并询问，不猜测路径
- 无同级参照目录 → 只评前三项，生态位标「待验证」
- 目标 skill 过小（<20 行） → 判「雏形」，不做拆分建议
- 意图识别不可用 → 手工提取意图，标注渠道缺失
- 被审计对象是本技能自身 → 使用独立外部检查器与清单，避免自我辩护偏差
