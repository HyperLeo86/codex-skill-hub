# 御前会议（Small Council）

**版本**：0.1.0（2026-08-07）

## 概览

把高风险、多步骤、多 agent 的交付任务变成「分权 + 证据 + 状态机 + 人工门」的治理系统：实现、审查、发布、记账角色分离，流程可恢复，失败可沉淀。

## 触发与反触发

- 触发：帮我编排多个 agent 完成一批任务；让多个子代理协作交付，但我要能随时叫停；这个流程太依赖单个 agent 的自觉，帮我加上审查和证据；把多任务交付做成可恢复、可审计的流程；给我搭一套 agent 治理框架；多个任务按依赖顺序交付，怎么保证质量和安全；让 agent 又写又审又发布太危险，建一套分权流程
- 反触发：单个任务的直接实现；写一份普通说明文档；市场调研或竞品分析

## 决定权（自由度 medium）

- 按伪代码/模板执行，参数可依上下文调整
- 输出格式遵循模板，内容允许合理变化

## 角色分工

| 角色 | 允许 | 禁止 |
| --- | --- | --- |
| Worker（骑士） | 实现、验证、结构化交接 | 发布、审查自己、擅自扩大范围 |
| Reviewer（学士） | 只读审查、给出发现 | 修改、发布、合并两轴排名 |
| 御前会议（父会话） | 调度、核对、发布、记账 | 直接编辑源码 |
| 用户（国王） | 人工门决策、授权 | — |

## 状态机

QUEUED → PRECHECK → WORKING → REVIEW → FIXING → VERIFYING → PUBLISHING → CLOSING → DONE；HUMAN_GATE / FAILED / BLOCKED 为暂停态。队列状态写 `<workdir>/.hyperleo-small-council/queue.json`，每任务一条记录（state/deps/base/evidence/decisions）。恢复 = 读状态 + 对照外部事实源，只补缺失步骤。

## 工作流

0. Preflight：探测平台能力（子 agent/异步/隔离工作区/事实源），确认任务、依赖、验收标准、禁止范围、人工通道；能力缺失 → 降级串行或停止。
1. 建契约：每任务一张契约卡：角色、验收标准、禁止范围、证据要求、升级规则；角色不得兼任。
2. 建队列：拓扑排序、检循环依赖；跳过已交付完整者；初始化状态文件。
3. 调度：依赖任务串行；独立任务在隔离工作区并行（默认 2）。每任务一个 fresh worker。
4. 交接：worker 返回结构化字段（changed/commands+exit codes/acceptance_map/unfinished/risks/pending_questions）；父会话对照事实源核对；不一致 → HUMAN_GATE。
5. 审查：两个 fresh、只读 reviewer 独立跑 Spec 轴（对照任务要求）与 Standards 轴（对照规范）；两轴分开保留；返修 ≤3 轮，第 2 轮起只审 delta。
6. 验证：父会话亲自运行最终验证并检查输出；失败且额度用完 → HUMAN_GATE。
7. 发布：只有御前会议执行不可逆操作（推送/合并/部署/关闭）；发布规则无法确认 → HUMAN_GATE。
8. 回填：回填最终证据、残余风险；更新状态文件；确认外部事实源一致。
9. 恢复：中断后读状态文件，按状态 + 事实源分类恢复，不重做已完成步骤。
10. 总结与回灌：输出汇总表；本次失败写入 references/regressions.md；命中已知失败模式必须写防复发条款。

## 人工门（任一即停）

需求/范围/架构无法确认；权限或凭据缺失；未授权费用；破坏性操作；证据不一致；第三轮审查仍阻塞；验证额度耗尽后失败；协议失败；状态无法确认。

## 维护纪律

- 每次真实使用后把失败写入 references/regressions.md；升级前全量回归，存在「未修复」不得升级。
- 模型/运行时升级后，先跑回归账本全部场景，再删旧补丁；不可删的注明适用版本。
- 优化-验证循环最多 3 轮，超限交用户决策。

## 验收（来自契约）

- 每个任务有独立实现/审查/发布角色，且任一角色不兼任另一角色
- 每个任务的完成都有 ≥3 类可核验证据（diff/命令退出码/远端状态）
- 流程状态持久化，中断后可按状态恢复且不重做已完成步骤
- 不可逆操作前有显式人工门，未获授权即暂停不跳过
- 输出汇总表，并把本次失败写入回归账本

## 失败降级

- 平台无子 agent/异步能力 → Preflight 探测失败：降级为串行单会话或停止，不假装并行
- 无法生成可核验证据 → 标注「待验证」，禁止声称完成
- 队列状态文件丢失/损坏 → 以 git/Issue 等外部事实源重建，只补缺失步骤
- 人工门未获答复 → 保持暂停态，不自动跳过或继续
- 角色冲突（同 agent 兼任写与审） → 契约校验失败，重新分配角色后再启动
