# 建议层模板与证据追溯

建议层 = 关系视角分析 + 行动建议。每条建议必须能指回事实层证据（区块 + 来源 + 置信度）。

## 模板

```markdown
## 透镜层：<透镜名>视角
- 关系定位：<一句话：对方与你的关系下，最值得注意的事实>

## 建议层
### 行动建议
1. <建议>（证据：事实层 §区块 / 来源 URL / 置信度）
### 风险与边界
- <该透镜下的反证、软肋、待确认项>
```

## 各透镜建议格式

| 透镜 | 建议格式 | 必须包含 |
| --- | --- | --- |
| 老师 | 思想地图 | 核心概念/出处/可迁移原则/认知边界 |
| 陌生人 | 人物速写 | 一句话定位/独特标签/连接点 |
| 博弈对手 | 能力×意图×机会矩阵 | 能量清单/风险场景/防守建议/预警信号 |
| 潜在商业伙伴 | 兴趣点地图 + BATNA/ZOPA 草图 | 诉求/互补性/尽调红旗/接近策略 |

## 证据追溯规则

- 无证据的建议不写；证据不足写「待确认」。
- 冲突事实进「风险与边界」，不压成单一口径。
- 建议 ≤3 条，每条 ≤60 词，突出可执行性。
