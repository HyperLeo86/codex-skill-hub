# 事实层输出模板（v0.2）

事实层只输出证据，不输出解读；解读归透镜层，建议归建议层。

## 事实层结构（5 个必需区块）

```markdown
# 人物情报卡：<姓名>（<昵称/ID>）

> 消歧声明：<如存在同名风险，写明本次锁定的人物与依据；无风险写「无」>

## 1. 身份速览
- 姓名 / 别名 / 常用 ID
- 现职与机构 / 所在地 / 公开主页

## 2. 履历时间线
- 教育 / 职业经历 / 重要节点（带年份）

## 3. 代表作与关键资产
- 作品/产品/项目/成就（含可量化指标）

## 4. 网络足迹
- 官方站 / 社交账号 / 专业主页（URL 列表）

## 5. 证据分级
- 每条关键事实：`事实 — A/B/C/D — 来源1、来源2`

## 6. 缺口与待确认
- 查不到 / 有冲突 / 需要用户补充的字段
```

## 透镜层与建议层

- 透镜层：按 `lens-registry.md` 选择，输出「关系视角分析」。
- 建议层：按 `advice-templates.md` 输出行动建议 + 证据追溯。
- 公众形象与舆论不再作为固定区块：老师看思想口碑、对手看冲突记录、伙伴看履约评价——按透镜定向补查。

## 置信度分级

| 级别 | 定义 | 处理 |
| --- | --- | --- |
| A | ≥3 个独立来源一致，或含官方一手来源 | 直接写入正文 |
| B | 2 个独立来源一致 | 写入正文，标注 B |
| C | 单一来源或官方自述 | 写入正文，标注 C |
| D | 冲突/未证实/猜测 | 不写入正文，进「待确认」 |

## 来源列表

每条事实附：`来源名 | URL | 访问日期`。来源列表追加在画像末尾，不算入 1800 词正文。
