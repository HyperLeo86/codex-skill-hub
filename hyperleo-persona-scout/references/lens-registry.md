# 关系透镜注册表

透镜 = 核心问题集 + 定向补查 + 证据权重。事实层不变，透镜层决定「怎么解读、补查什么、建议什么」。

## 内置透镜

### 1. 老师（师者透镜）

- 定位：从对方身上提取可迁移的思想与认知。
- 核心问题：他的核心洞察是什么？哪些思想可迁移到我的场景？他的思维模型/决策启发式？认知边界（哪些领域他会误导我）？
- 定向补查：访谈、著作、演讲、课程、长文、播客。
- 证据权重：一手表达（访谈/著作）> 二手转述 > 八卦。
- 建议层模板：`思想地图`（3-7 个核心概念 + 出处 + 可迁移原则 + 认知边界警告）。

### 2. 陌生人（好奇透镜）

- 定位：快速理解「他是谁、为什么值得注意」。
- 核心问题：他是谁？人生有什么独特节点？有什么作品/标签？与我有什么潜在连接点？
- 定向补查：人生时间线、轶事、社交足迹、代表作。
- 证据权重：广度优先，弱化深度论证。
- 建议层模板：`人物速写`（一句话 + 独特标签 + 潜在连接点）。

### 3. 博弈对手（威胁透镜）

- 定位：评估对方的能量与破坏力，准备防守/应对。
- 核心问题：他有什么能量（资源/关系/筹码）？破坏力 = 能力 × 意图 × 机会？软肋/约束/红线？可能策略与我方应对？
- 定向补查：权力资源、历史冲突/诉讼/竞争记录、谈判风格、敌意信号、言论立场。
- 证据权重：行为记录 > 自述 > 传闻。
- 建议层模板：`能力×意图×机会矩阵` + 防守建议 + 预警信号。

### 4. 潜在商业伙伴（合作透镜）

- 定位：判断要不要合作、怎么谈。
- 核心问题：他想要什么（利益与诉求）？能力与我互补吗？信用与履约记录？决策链/话语权？合作风险（利益冲突/退出成本）？
- 定向补查：公司/项目/招投标记录、合作伙伴评价、LinkedIn/推荐信、财务与诉讼记录。
- 证据权重：履约记录 > 商业自述 > 社交形象。
- 建议层模板：`兴趣点地图 + BATNA/ZOPA 草图 + 尽调红旗 + 接近策略`。

## 自定义透镜注册

新透镜 = 一句话关系定义 + 3-5 个核心问题 + 定向补查渠道 + 证据权重 + 建议模板。新增后先小验证（1 个真实案例）再固化进本表。

## 透镜切换纪律

- 事实层只检索一次；换透镜只重跑第 3 步定向补查与第 4 步建议层。
- 每透镜的建议必须引用事实层证据（A/B/C/D），无证据标「待确认」。
