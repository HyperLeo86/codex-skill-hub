# 风格与契约化写法

## 术语与定义条款

- 关键业务名词在文首「定义条款」给出：`「客户」指…；「甲方」指…`。
- 全文同一概念同一叫法，不自造词。

## 强制词

- `must` / `should` / `may` 按 acceptance-guide.md 使用。

## 量化口径

- 指标必须带：口径（怎么算）、周期（何时观察）、数据源（哪里取数）。
- 反例：「提升效率」；正例：「同等工单量下创建总耗时降低 ≥60%，口径…，周期上线后 2 周」。

## 书面变更

- 任何变更必须：版本号 + 变更记录 + 影响评估 + 谁确认。
- 口头变更记录为 RFI/CR，未落字不算数。

## 排版

- Markdown + Mermaid 图表；表格不放长文本；错误提示/文案用引号；状态用状态图。
