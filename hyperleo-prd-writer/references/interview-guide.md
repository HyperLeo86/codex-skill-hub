# 三视角访谈题库

## 原则

- 确认型问题优先：给候选答案让甲方选，而不是让甲方描述。
- 每轮 ≤3 问；按最低分维度定向追问（见 quality-rubric.md）。
- 记录格式：Q/A + 未确认项（标 `[待确认]`）。

## 用户视角（谁用、做什么）

1. 谁会用这个功能？他们现在怎么完成这件事？（给选项：手工 Excel / 电话 / 别的系统）
2. 一次使用大概多长时间、多频繁？
3. 主流程是不是这样：…（复述）→ 只需确认/修正。
4. 如果这个功能做不出来，用户现在最痛的一步是什么？
5. 权限上谁能用、谁不能？（给角色选项）

## 业务视角（为什么做、做到什么程度）

1. 不做这件事，损失是什么（钱/时间/风险/合同）？
2. 成功怎么量化？给 2–3 个候选指标让用户选/改。
3. 本期必须交付的最小闭环是什么？哪些明确不做？
4. 有哪些外部依赖（数据、法务、第三方系统）？谁负责？
5. 有没有合规/审计/口径要求？

## 技术视角（约束、集成、边界）

1. 必须对接哪些系统？对方提供什么接口/文件？
2. 数据量级、性能要求？（给档位：百/千/万/百万）
3. 安全与权限模型？（登录、角色、审计）
4. 有没有既定技术栈/部署环境约束？
5. 已知会踩的坑/历史包袱？（存量数据、旧逻辑）

## 从一句话起步的追问顺序

1. 给谁用、解决什么事（用户）
2. 现在怎么做、最痛在哪（业务）
3. 不做会怎样、成功标准（业务）
4. 要接什么系统、有什么硬约束（技术）
5. 本期做到哪、不做哪（范围冻结）
